Will your Roblox script work when a player goes back?

Our checkpoint script worked when a player moved forward. Walking back to an earlier checkpoint sent them to the wrong place after a reset. You can use the same test on a script your AI wrote.

Watch the player respawn. This 14-second recording shows our own game in Studio and the result in Baseplate Free. Play the replay.

One player action, two results

  1. In a copy of the obby, reach checkpoint 3, return to checkpoint 1, then reset. The rule for this game is to respawn within 8 studs of the highest checkpoint reached in the current session.
  2. Run the check in Studio. Our first respawn was 44.03 studs from checkpoint 3. Returning to checkpoint 1 had overwritten the player's progress.
  3. Review the edit and repeat the route in a fresh play session. We changed the handler by hand. The second respawn was 4.71 studs from checkpoint 3. Saving progress between sessions needs a separate test.

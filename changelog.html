What shipped, and when

Dated release notes for the Baseplate desktop app. Bug fixes and dependency bumps are folded into the release they shipped in rather than listed individually.

0.22.02026-10-05Latest
  • From setup to a result. Guided project and CLI setup, explanations for each tool and step-by-step Bridge/MCP connection instructions.
  • A map of your existing game. Directed script dependencies, recognized remote calls and source inspection, with suggested next steps you can plan on the Board.
  • Safer playtest results. Test tasks require evidence from the current project and session. Changes invalidate old results; errors remain visible with recovery instructions.
  • Updates that respect your work. Download progress, retry, deferred restart and active-work protection. A failed Windows installer launch keeps the app open. Store updates come through Microsoft Store; Mac updates use the manual DMG path.
  • Polish and reliability. Transparent taskbar icons, simpler DataOps edits and fixes across Board, Verify, Regression and snapshots. Mac builds include the correct native terminal dependency for Intel and Apple Silicon.

Your AI provider's access and usage limits still apply. Mac downloads remain unsigned by an Apple Developer ID; see the installation and update guide. Microsoft Store availability follows its certification and rollout independently.

0.21.02026-10-02
  • A clear first improvement. Open your existing game, choose a bug fix, a small feature or a local scan, and follow the next step. Task drafts stay with their project.
  • Your AI, easier to choose. A custom chooser explains installed tools, account states and supported modes. Updated Codex, Cursor and Grok integrations; Windows Gemini launchers no longer fail with “File not found”.
  • Guided Open Cloud setup. Find your game IDs and permissions, then test actual read access. Saving a key is separate from a verified connection.
  • Plans and safer Studio edits. See the agent’s steps, review supported structural changes and use bridge 0.18.1’s more reliable Revert after renames or moves. Restart Studio after updating the bridge.
  • A game map and faster startup. Explore source-based suggestions; secondary tools and guidance load when needed. Updated dependencies and checked clean installation, upgrades and packaged desktop startup.

AI access and usage limits belong to your provider. Gemini CLI requires an API key or an eligible organization account; Antigravity offers Native/MCP for personal Google accounts. Mac downloads have no Apple Developer ID signing or notarization; see the installation guide.

0.20.02026-08-08
  • A complete clean UI system. Agents, Board, Labs, Studio, dialogs and pricing now share tested typography, spacing, controls, contrast and motion.
  • Agent changes you can see and undo. The live Studio ledger describes each edit and offers an exact Revert action where a safe reversal exists.
  • Scope Guard for existing games. Agents must inspect the place first and cannot silently restructure work outside the request.
  • The game beside the conversation. Agent tiles can show the Studio viewport, selection, runtime errors and recent changes.
  • Safer Creator Store assets. Agents can search the Toolbox with script-risk metadata before inserting a model.
0.19.02026-07-23
  • Studio Copilot with vision. The agent can see the Studio viewport rather than reasoning about the game purely through code and logs.
  • Question mode in the Studio plugin, plus a reworked panel: the prompt lives in the dock, edits go through the recording API so they land in the normal undo history, and the agent can highlight and focus objects in 3D.
  • macOS support for the Studio view, and packaging fixed so it does not ship broken.
0.18.22026-07-22
  • Voice Prompt works on the desktop app — audio is recorded locally and transcribed with your own speech key.
  • The Studio bridge survives Roblox auto-updates. Studio updating itself used to quietly break the connection; the bridge now re-establishes it, with a live preflight check on Play control instead of assuming a file's presence means it works.

0.17.x2026-07-21
